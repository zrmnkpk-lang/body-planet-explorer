## 已实现

- 统一索引化二十面体地形，共享三维高度场，全球网格为闭合流形。
- 首屏相机从原 4.5 移到 3.7，保留按住后拖拽、滚轮、双指、方向键、自动旋转和区域聚焦。星球本体使用四元数旋转，穿过冰川极区时不受相机俯仰边界限制。拖动方向与地表移动方向一致，旋转通过逐帧插值平滑过渡，阴影在旋转完成后更新。
- 三维分形噪声、域扭曲、低频连续山脊和高原肩部、海岸过渡、海拔雪线、坡度裸岩与岩层着色。所有主要大陆都有宽缓起伏，造山带保留局部重点；大范围的岩层明暗使山势略带几何切面，避免密集尖峰。
- 主河道与多块大陆上的干流、支流、三角洲分汊及不规则湖泊；高度场先塑造河谷，贴合河谷的带状水面与河岸共用参数。水位沿下游下降，流向通过水面线条亮度变化提示。四条潮汐峡湾深入北部冰原，与外海接通。
- 2,400 树木实例，四种针叶树轮廓；约 4,400 个低矮植被实例，另含岩石和冰川。深青林带主要分布在湿润大陆，赤砂大陆和西境干旱带降低树木密度；坡度、海拔、湿度和河岸距离共同控制密度，无规则阵列。
- 哑光分层材质、局部法线细节、轻度明暗分阶、地形与植被阴影、水面和冰体粗糙度差异。
- 两个原创程序化 GLB 地标：层岩山脊、裂隙冰舌。生成源随仓库保存，可替换成后续美术精修模型。
- 低成本球形拾取代理限定射线范围，再用同一高度场求交和经纬度分类；拾取开销与可见三角面数无关。
- HTML 地标标签仍由 `landmarks.js` 维护，背面隐藏；区域细节来自 `src/planet/zones.js`。
- 高度计算在 Web Worker 中完成，渲染期间加载细分。标准/精细画质切换，精细档像素比上限 2。地图内容层级在两档画质中保持一致。

Three.js 此版本 `IcosahedronGeometry(radius, detail)` 的面数为 `20 × (detail + 1)²`。本项目使用 `detail=63/127` 得到约 8 万/33 万面；不能直接将方案中的递归细分级数 6/7 当作 Three.js 参数。

## 数据绑定

稳定 zone ID：`muscle`、`water`、`bone`、`fat`。默认展示模拟数据。修改静态数据可编辑 `src/planet/zones.js`；同页宿主应用可发送：

```js
window.dispatchEvent(new CustomEvent('body-planet:metrics', {
  detail: { muscle: 29.1, water: 57.2, bone: 2.9, fat: 21.8 }
}));
```

只接收已知区域的有限数值，更新卡片展示。真实 APP 的 `src/PlanetView.tsx` 会在数据页修改体成分后向同源 iframe 发送这个事件；它仍不修改服务端账本。`explore_body_planet` 页面工具契约继续保留。

左侧五级入口可保持当前观察方向切换尺度。局部地形按屏幕中心方向生成，拖动到新位置时后台更新，不要求先点击身体区域。加载期间保留完整基础球。`src/planet/view-levels.js` 统一管理层级距离、缩放百分比与细节权重；`landmarks.js` 的 min/maxDetailLevel 与 priority 管理标签进退场。

`src/planet/climate.js` 使用低面数实例云、1,600 条 GPU 气流粒子和 720 条 GPU 降水粒子组成独立气候层。气流与降水的位移、循环和拖尾在顶点 Shader 中计算，JavaScript 每帧只更新统一时间与显隐权重。云层使用独立 ShaderMaterial 生成分层明暗、边缘光和缓慢漂移；海洋材质注入双向流场高光，随气候层逐渐增强。系统“减少动态效果”开启时会停用闪电，风线和风带仍保持缓慢流动。

新增回归检查覆盖岛链高度、五级缩放、远景地形简化、气候层、地表完整展开、反向缩放收起、阈值防抖以及显隐过程中实例矩阵不变。GPU 过渡画面与帧率仍需实机验收。

回归检查覆盖七处主要大陆的地形起伏、两块干旱带与其余大陆的森林覆盖。山脉使用宽频高度场，森林的远景着色与近景实例共用同一遮罩。冰川、河床和身体区域的原有坐标与拾取契约不变。

缩小视角的海岸使用由全球高度场生成的窄色带描边，大陆和海岛轮廓更清楚；随缩放淡出描边，近景保留地表本身的细节。远景顶点色去除高频噪点。云层按四档尺寸组织，大型云雾由相邻云瓣连接成片，亮度与透明度独立于雨云。拖拽期间停用局部细分切换，保持全球细分网格连续显示；松开稳定后重建观察位置的局部地形。树木渐显采用正常透明过渡，完整显示后再参与阴影；灌木不投射细碎阴影。地形自身阴影关闭，阴影分辨率设为 1024，拖动时约每 32 毫秒更新一次阴影贴图。实例出现前地表已经恢复完整高度，避免缩放期间相对地面浮动。

针对缩小后发亮、近景发油的观感，地表和海水改用漫反射材质；远景屏蔽高频法线扰动，近景纹理按缩放逐步显现。降低主光与补光强度，减轻明暗色阶对局部的压暗。森林由近黑色调整为中深青绿，岩层与雪线降低明度反差；海洋流场保留轻微色差，去除镜面高光。大型白云随缩放逐步变淡，让中景气候层露出雨云和地表。森林、高原、冰川、海岸与区域点击逻辑继续使用同一高度场和原有数据坐标。

赤砂大陆和西境大陆的荒漠带使用同一高度场中的干旱遮罩，赭红沙地、岩层及森林边界连续过渡。增加少量地形细微起伏，并将沙地风纹、岩石颗粒和冰川裂隙分别放在 GPU 程序化纹理中；地貌属性随顶点传到 Shader，缩放进度逐渐提高颜色纹理与漫反射法线凹凸的强度。`fwidth` 过滤亚像素细节，UV 缺失不会形成接缝。此版本无需下载图片纹理贴图；以后若为独特地标制作高精法线、AO 和专属美术纹样，可作为独立资产加入。


## 非对称大陆与海岸

参考真实地图中半岛、海湾、地峡和岛弧的比例，重新设计原创大陆轮廓。西境包含深海湾与岬角，季风大陆向南收窄，赤砂大陆包含东侧内凹海湾与南伸半岛，背面湿润大陆采用分叉北岸和狭长南端；海岛改为弯曲的狭长岛弧，并补充小岛。

轮廓在球面局部切平面中构造，预计算 192×192 有符号距离场。高度场叠加原有三维海岸噪声，全球、近景、局部网格及植被、拾取使用同一结果。既有地标 ID、区域绑定与河流路径保持兼容。植被采样增加有界补足逻辑，避免海湾增多后森林/灌木数量不足。

校验新增海湾开口、半岛存续和河流陆地覆盖检查；另以高度场直接采样世界分布图，检查轮廓差异与经度边界连续性。此离线检查不等同于浏览器 GPU 画面验收。


## 冰川峡湾与河口三角洲

北部冰盖刻入四条连通外海的峡湾，沿峡湾中心线降低共享地形高度，并铺设贴海水面。峡湾与冰面使用同一地形采样，水域点击也沿用同一分类。

新增中央大陆与赤砂、岬湾、南风、东岚大陆的分级水系。河网包含主干、一级支流、二级支流和更细的源头溪流；每条支流有明确的汇流点，汇入时水位与母河衔接，沿下游下降。河宽逐级收细，生态层（缩放约 54%–72%）展开细支流。各河道与地形共用中心线距离场，刻出对应窄河谷，三角洲从主河口展开分汊。植被湿度读取同一河网，河岸生态沿支流延伸。

## 小型大陆与冰川起伏

新增岬湾大陆、南风大陆、东岚大陆，位于三个开放海盆；每块陆地带有独立半岛和海湾，沿用共享山地、湿度、森林分布。名称与坐标仍由 `src/landmarks.js` 管理。

北部冰川使用围绕北极的球面轮廓，形成深浅不同的冰湾和南伸冰舌。海岸、冰雪颜色、植被排除和区域点击共同使用该冰川掩码；高纬海湾按水域识别。冰川内部增加宽缓台地、连续低山脊及弯曲冰谷，较陡坡面使用蓝灰冰色，高处缓坡保留象牙白积雪。所有起伏进入统一高度场，随细分显示同一地貌。

回归检查增加小型大陆起伏及海峡、极地海湾/冰舌、冰原内部高差与高纬水域点击分类。离线世界分布图用于检查轮廓，实际 GPU 画面与帧率尚需实机确认。

## 河口边界、曲流与海峡岸线

河流中心线采用经过控制点的 Hermite 曲线，并叠加有界、不等幅的弯曲；支流末端重新绑定母河的真实曲线位置。河面横截面沿局部切线的法向铺设，避免弯道处水带宽度不一致。原有河流级别、缩放显隐和身体数据接口保持兼容。

`sample(x, y, z, false)` 提供未刻蚀河谷的自然地形高度，用于海陆判断。十二条三角洲分汊在初始化时通过二分定位真实海岸，末端水位降到海平面；河面仅提交两岸及中心仍在陆地内的三角形。河谷只下切，不抬升海底；河口外不再产生悬浮青色水带。峡湾仅在冰川岸内叠加浅水颜色，外海由统一海面承接。

海岸叠加仅作用于近岸的多尺度三维扰动，海峡增加不等幅岸线凹凸及两处小岛。峡湾共用弯曲中心线，两岸宽度非对称、沿程变化，西北峡湾延伸进入冰盖内部。地貌随机性由固定参数生成，旋转、缩放和重新加载不会改变位置。

回归检查覆盖河口海平面衔接、自然海岸截断、可见河面顶点的陆地覆盖与河床对齐、汇流点/水位连续、曲流幅度和峡湾宽度变化。另检查离线高度场分布；真实浏览器 GPU 画面与帧率仍未在本环境验收。

## 冰旋与热带涡旋

天气层保留两处气旋：一处位于北部冰川上空，另一处位于西侧热带大洋。气旋每 30 秒形成一次，出现/衰减动画约持续 15 秒，其余时间保持无气旋的空档；两处按半周期错开。云墙和螺旋风带旋向为顺时针，旋转角速度与上一版相比提升至两倍；每轮按新的随机方向漂移，漂移速度也提升至两倍，并把路径限制在冰原或海洋上空。极地气旋使用冷蓝色和锐利冰晶高光，热带气旋使用低饱和灰红色；两种风带沿各自中心同步移动。时间、方向和色彩均由 GPU shader/实例属性驱动。回归检查覆盖中心地表类型、显隐时长、跨轮随机方向、漂移边界、旋向符号和两组配色。

气旋活跃时，细小全球气流也读取相同的周期、漂移中心和方向；在涡旋外沿半径约三倍（球面角半径 0.615 弧度）范围内逐渐加入顺时针旋转与向风眼收拢，边缘平滑衰减。影响仅存在于气旋约 15 秒的活动窗口，并随气旋消退还原；独立的季风宽带不参与该局部变形。GPU 顶点着色器只变换细气流顶点，不新增粒子或改变地表拾取。

天气联动补充：普通白云在活动气旋的约三倍风眼范围内淡出，避免涡旋周围云团堆叠。全球保留四个分散的乌云天气单元，各自拥有 20–30 秒随机周期与错开的开始相位；每轮持续时间独立落在 10–15 秒，并淡入淡出。乌云、局地雨线和闪电共享该单元的活动周期；每轮云团尺寸在基础值的 1–1.5 倍之间变化。冰川涡旋周边设有乌云禁入范围，且冰川涡旋不与乌云、雨线和闪电联动；热带涡旋仍可在风暴单元靠近时转暗并增强降水。四处风暴互不共用计时，时间、持续时长、尺寸都由固定种子复现。

- APP 首页继续复用 `planet.html?mode=app`，与 Sites 使用相同场景实现。水系映射仍归属身体水分区域；天脉长河的流动保留血液循环意象。
