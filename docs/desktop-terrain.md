# 桌面连续球面地形

## 入口与代码一致性

GitHub：`npm install` 后运行 `npm run dev`，访问 `/planet.html`。`/` 保持现有 React 训练工具。

Sites：[养星球 · 地貌探索](https://body-planet-explorer.kinteregla705706.chatgpt.site) 首页展示同一份 `planet.html` 场景。部署时仅将入口映射为 `index.html`；场景源码、地标和 GLB 资源保持一致。构建产物必须包含 worker 与 `public/assets/landmarks/`，不要只复制 HTML。

## 已实现

- 统一索引化二十面体地形，共享三维高度场，全球网格为闭合流形。
- 首屏相机从原 4.5 移到 3.7，保留按住后拖拽、滚轮、双指、方向键、自动旋转和区域聚焦。星球本体使用四元数旋转，穿过冰川极区时不受相机俯仰边界限制。拖动方向与地表移动方向一致，旋转通过逐帧插值平滑过渡，阴影在旋转完成后更新。
- 三维分形噪声、域扭曲、低频连续山脊和高原肩部、海岸过渡、海拔雪线、坡度裸岩与岩层着色。所有主要大陆都有宽缓起伏，造山带保留局部重点；大范围的岩层明暗使山势略带几何切面，避免密集尖峰。
- 主河道、两条支流、不规则湖泊；高度场先塑造河谷，贴合河谷的带状水面与河岸共用参数。主流和支流的水位沿下游下降，流向通过水面线条亮度变化提示。
- 2,400 树木实例，四种针叶树轮廓；5,600 低矮植被实例，另含岩石和冰川。共享森林遮罩将深青林带绘制到所有主要大陆的地表，近景实例沿林带展开；坡度、海拔、湿度和河岸距离共同控制密度，无规则阵列。
- 哑光分层材质、局部法线细节、轻度明暗分阶、地形与植被阴影、水面和冰体粗糙度差异。
- 两个原创程序化 GLB 地标：层岩山脊、裂隙冰舌。生成源随仓库保存，可替换成后续美术精修模型。
- 低成本球形拾取代理限定射线范围，再用同一高度场求交和经纬度分类；拾取开销与可见三角面数无关。
- HTML 地标标签仍由 `landmarks.js` 维护，背面隐藏；区域细节来自 `src/planet/zones.js`。
- 高度计算在 Web Worker 中完成，渲染期间加载细分。标准/精细画质切换，精细档像素比上限 2。地图内容层级在两档画质中保持一致。

## 精度配置

| 层级 | 三角面 | 启用条件 |
| --- | ---: | --- |
| 初始基础球 | 5,120 | 页面刚进入，后台加载后替换 |
| 全球球 | 81,920 | 远景、标准画质 |
| 大陆球 | 327,680 | 精细画质，相机距离小于 3.2 |
| 局部细分块 | 524,288 | 精细画质，当前观察方向，相机距离小于 2.2 |

局部块使用球面切平面投影、同一高度场和法线算法。基础球与局部块通过互补角度遮罩绘制；局部缓存只保留一个区域。表中的局部面数是提交面数，圆形遮罩会裁掉网格角部。

Three.js 此版本 `IcosahedronGeometry(radius, detail)` 的面数为 `20 × (detail + 1)²`。本项目使用 `detail=63/127` 得到约 8 万/33 万面；不能直接将方案中的递归细分级数 6/7 当作 Three.js 参数。

## 数据绑定

稳定 zone ID：`muscle`、`water`、`bone`、`fat`。默认展示模拟数据。修改静态数据可编辑 `src/planet/zones.js`；同页宿主应用可发送：

```js
window.dispatchEvent(new CustomEvent('body-planet:metrics', {
  detail: { muscle: 29.1, water: 57.2, bone: 2.9, fat: 21.8 }
}));
```

只接收已知区域的有限数值，更新卡片展示。此接口尚未接入 React 训练记录，也不修改体成分或训练的持久化状态。`explore_body_planet` 页面工具契约继续保留。

## 验证与剩余工作

运行 `node scripts/validate-planet.mjs`，检查全球闭合边、经度接缝、极点、向外法线、局部高度一致性、水流下降、四区域绑定与 GLB 完整性；运行 `npm run build` 检查两个生产入口与 worker 输出。

本次云端浏览器禁用了 WebGL，无法完成真实 GPU 画面、交互和帧率验收。进行了直接由实际网格生成的离线几何检查，发现并修复海面重叠；此检查无法替代浏览器着色器、局部拼接边缘与阴影验收。

1440p/2× 像素比是配置目标，尚无真实桌面 GPU 帧率测量。页面显示实时 FPS 便于实机确认。局部块切换目前为直接替换，后续可加入几何渐变；移动端专项 LOD、纹理法线/AO 烘焙、高模地标美术精修和屏幕空间 AO 仍待完成。当前不含外部 AI 生成的高模资产。


## 地貌图鉴 3.2：连续缩放、岛链与气候层

采用深靛蓝海洋、青绿林地、赤铜岩层与冷白冰川。海洋增加浅海色带，岩面保留较强的分层明暗，减少远景细碎色噪。

| 地图层级 | 典型相机距离 | 主要内容 | 标签 |
| --- | ---: | --- | --- |
| 天际 | 4.20 | 星球轮廓、极地、稀疏薄云，26% 远景地形起伏 | 无 |
| 板块 | 3.45 | 大陆、浅海、七组大洋岛弧 | 大陆、冰川、海洋、群岛 |
| 气候 | 2.78 | 雨云、气流、主河道 | 河流、荒漠、群岛 |
| 生态 | 2.12 | 完整针叶林、支流、湖泊与主要山体 | 森林、融水湖、河谷 |
| 地表 | 1.53 | 灌木、碎石、冰体、GLB 地标、岩面细节 | 岩层、林冠、冰舌、湿地 |

相机距离映射为 0–100% 缩放进度。云层、地名、雨云、气流、水系、山体、植被和地表细节分别使用连续显隐区间，前 80% 完成主要信息展开。地形顶点在远景压低起伏，进入生态层后恢复完整高度；共享高度场、河流参数与身体区域分类保持一致。标签按缩放进度淡入淡出，并继续执行遮挡判断和碰撞避让。

左侧五级入口可保持当前观察方向切换尺度。局部地形按屏幕中心方向生成，拖动到新位置时后台更新，不要求先点击身体区域。加载期间保留完整基础球。`src/planet/view-levels.js` 统一管理层级距离、缩放百分比与细节权重；`landmarks.js` 的 min/maxDetailLevel 与 priority 管理标签进退场。

`src/planet/climate.js` 使用低面数实例云、1,600 条 GPU 气流粒子和 720 条 GPU 降水粒子组成独立气候层。气流与降水的位移、循环和拖尾在顶点 Shader 中计算，JavaScript 每帧只更新统一时间与显隐权重。云层使用独立 ShaderMaterial 生成分层明暗、边缘光和缓慢漂移；海洋材质注入双向流场高光，随气候层逐渐增强。系统“减少动态效果”开启后统一时间冻结为零。

新增回归检查覆盖岛链高度、五级缩放、远景地形简化、气候层、地表完整展开、反向缩放收起、阈值防抖以及显隐过程中实例矩阵不变。GPU 过渡画面与帧率仍需实机验收。

本轮加入七处主要大陆的地形起伏、森林覆盖和树冠分布回归检查，山脉使用宽频高度场，森林的远景着色与近景实例共用同一遮罩。冰川、河床和身体区域的原有坐标与拾取契约不变。

缩小视角的海岸使用由全球高度场生成的窄色带描边，大陆和海岛轮廓更清楚；随缩放淡出描边，近景保留地表本身的细节。远景顶点色去除高频噪点。云层按四档尺寸组织，大型云雾由相邻云瓣连接成片，亮度与透明度独立于雨云。拖拽期间停用局部细分切换，保持全球细分网格连续显示；松开稳定后重建观察位置的局部地形。树木渐显采用正常透明过渡，完整显示后再参与阴影；灌木不投射细碎阴影。地形自身阴影关闭，阴影分辨率设为 1024，拖动时约每 32 毫秒更新一次阴影贴图。实例出现前地表已经恢复完整高度，避免缩放期间相对地面浮动。

针对缩小后发亮、近景发油的观感，地表和海水改用漫反射材质；移除地表高频法线扰动，改用仅在近景出现的微弱颜色纹理。降低主光与补光强度，减轻明暗色阶对局部的压暗。森林由近黑色调整为中深青绿，岩层与雪线降低明度反差；海洋流场保留轻微色差，去除镜面高光。大型白云随缩放逐步变淡，让中景气候层露出雨云和地表。森林、高原、冰川、海岸与区域点击逻辑继续使用同一高度场和原有数据坐标。
