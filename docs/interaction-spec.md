## 阅读说明

本文件记录当前前端原型的实际行为。Figma 中的页面图片为现状定位截图；交互条目、流程和表格为原生可编辑图层。不是功能完成或测试通过的声明。截图数据为代码预置模拟值。

状态：**已实现**=代码已连接交互；**原型**=静态/模拟展示；**待完善**=现状差距及后续建议。

## 01 导航与核心流程

训练：星球主按钮 → 训练选择 → 进行中 → 结算 → 生态 / 返回选择。

数据：数据 → 展开录入 → 编辑即时更新 → 保存反馈 → 生态详情数值同步（当前不重建地貌）。

探索：生态 → 加载轮廓 → iframe onLoad → 画布淡入 → 旋转/缩放 → 鼠标选区 → 详情 → 拉近观察 / 返回全貌。

### N-01 底栏导航 · 已实现 · 五页切换

星球(home) / 训练(workouts) / 生态(portal) / 数据(stats) / 我的(profile)。
切换只修改 React 标签状态，URL 保持 /；选中标签高亮。
各页滚动回到顶部，父级业务状态保留；生态 iframe 重新进入时重建。

依据：src/App.tsx · activeTab / keyed app-scroll

### N-02 状态生命周期 · 已实现 · 仅会话内

训练阶段、任务勾选、周进度、指标与提醒开关保存在内存。
浏览器刷新恢复默认值，无账户/设备/服务端数据源。
截图使用 APP 预置模拟指标，不代表用户真实身体数据。

依据：src/App.tsx · useState

### N-03 视觉与动效约定 · 现状规范

应用保留宇宙背景图与半透明灰白卡片；首页小球为透明圆形预览。
生态场景保留完整探索画布；减弱动态时停止自转并关闭闪电。
截图为定位参考，本文流程、表格、规则与导航为原生可编辑图层。

依据：src/index.css / src/app.js · reduced

## 02 · 星球页

阶段浏览、日常任务与训练入口

### H-01 五阶段浏览 · 已实现 · 展示切换

触发：点上一/下一阶段；触屏水平滑动超过 40px。
反馈：五阶段循环切换图片、名称、说明、贴纸与指示点。
边界：左滑下一阶段，右滑上一阶段；仅换卡片内容，不重建球体。

依据：src/App.tsx · switchEra / onTouchEnd

### H-02 旋转小球 · 已实现 · 只读预览

进入首张卡片自动显示缓慢旋转的 122×122px 星球。
透明画布 + 圆形裁切，直接叠在阶段图片上，无深空底色与星点。
边界：不接受点击/拖动；完整探索入口在「生态」。

依据：src/App.tsx / src/app.js · snapshot

### H-03 开始今天的训练 · 已实现 · 页面跳转

触发：点击主按钮。
反馈：切换到「训练」，训练阶段重置为模式选择。
数据：保留上次选中的训练类型；不会自动开始计时。

依据：src/App.tsx · openTraining

### H-04 每日任务与经验值 · 已实现 · 手动标记

点击查看/详情展开单条任务；再次点击收起，最多展开一条。
标记完成/撤销完成更新任务计数及 XP；奖励依次为 120/80/40。
XP = 680 + 已完成任务奖励；默认 800；不校验运动、步数或饮水。

依据：src/App.tsx · completedTasks / selectedTask

### H-05 本周训练进度 · 已实现 · 手动勾选

点击七个日期按钮可独立切换完成状态；默认完成周一至周四。
显示已勾选数量 / 5，训练结算不会自动增加次数。
边界：可选 7 天，当前可能出现 7/5 和 140% 进度，需后续封顶。

依据：src/App.tsx · weeklyDone

### H-06 跨维度菜单及展示入口 · 待完善 · 已记录实际行为

「全部训练」只切换训练标签，保留之前的训练阶段。
首页点击某训练行只修改隐藏的训练状态，当前页不跳转。
「换个说法」、顶栏奖励暂未绑定操作；等级解锁为固定文案。

依据：src/App.tsx · startWorkout / home view

## 03 · 训练页

模式选择 → 训练进行中 → 训练结算

### T-01 选择与开始 · 已实现 · 状态流转

默认「季风有氧」；点开始进入进行中，点任意模式行立即开始该模式。
三模式：造山力量 45min/310kcal；季风有氧 30min/420kcal；晨雾恢复 20min/160kcal。
边界：无开始确认；模式卡上的已完成状态为固定数据。

依据：src/App.tsx · activeWorkout / workoutModes

### T-02 进行中界面 · 原型 · 固定展示

显示训练标题、12:48 与组数 2/4；当前计时和组数不会推进。
进行中仍可点击其他模式行，直接切换训练。
边界：尚无暂停、恢复、取消或防误触确认。

依据：src/App.tsx · trainingPhase === active

### T-03 完成训练 · 已实现 · 结算展示

点击完成训练切换 summary，展示所选训练的预设时长、+46 XP 文案与生态事件预告。
数据：仅改变训练阶段；未写入 XP、每日任务、本周次数或训练历史。
边界：生态事件为文字预告，尚未改变地貌。

依据：src/App.tsx · trainingPhase === summary

### T-04 结算后的两个去向 · 已实现 · 页面跳转

「去星球看看」：重置模式选择状态，并进入生态页。
「返回模式选择」：回到训练选择页，保留所选模式。
切换底栏会保留阶段；再次进入训练时显示原阶段。

依据：src/App.tsx · summary actions

### T-05 真实训练闭环 · 待完善 · 功能建议

建议建立真实计时、暂停/恢复、训练记录、奖励和任务联动。
完成结算应只入账一次；重复点击与刷新需有明确恢复规则。
此条为后续需求，不代表当前 APP 已实现。

依据：交接建议 · 对应 G-01/G-02

## 04 · 生态页

探索身体星球与查看体成分映射

### E-01 加载态与显现 · 已实现 · iframe 加载反馈

进入页面显示模糊球体轮廓与「正在加载身体星球…」。
iframe onLoad 后画布淡入 420ms、加载层淡出 320ms。
边界：onLoad 只代表文档加载；并非 Worker、GLB 与首帧全部就绪。

依据：src/PlanetView.tsx · frameReady

### E-02 旋转与缩放 · 已实现 · 场景操作

鼠标左键长按 180ms 后拖动旋转；滚轮或双指缩放。
触屏单指立即进入旋转；自动旋转按钮可切换；无平移。
加号 ×0.84 / 减号 ×1.19；观察距离限制 1.48–5.6。

依据：src/app.js · pointer / zoom / controls

### E-03 区域详情与聚焦 · 已实现 / 触屏待完善

鼠标短按、位移小于 7px 时拾取地貌，显示选中区域详情与高亮，停止自转。
点球外关闭详情；「拉近观察」聚焦该区域。
触屏按下即消费旋转手势，当前轻点难以触发拾取；需区分点击与拖动。

依据：src/app.js · pick / select / holdConsumed

### E-04 返回全貌与键盘 · 已实现 · 场景操作

返回全貌关闭详情，恢复球体朝向与初始距离，并关闭自转。
场景获焦后方向键旋转，+/- 缩放，Esc 重置。
靠近球体逐级展示板块、气候、生态、地表细节；背面标注隐藏。

依据：src/app.js · reset / keydown / LOD

### E-05 地形比例与身体指标 · 已实现 · 展示映射

地图下方依次显示造山带↔肌肉、深蓝寰海↔水分、极地要塞↔骨量、季风大陆↔体脂。
四条比例为独立归一化显示值，不是相加 100% 的地表面积。
「呼吸状况：稳定」固定显示，未接入呼吸测量数据。

依据：src/App.tsx · terrainReports

### E-06 数据同步与异常 · 待完善 · 边界已标注

合法数值通过同源事件同步区域详情；目前不重建山脉、河流或冰盖。
Worker 失败保留基础球体；渲染器创建失败/上下文丢失有场景错误提示。
APP 外层暂无超时、重试、首帧就绪协议；切离生态会销毁 iframe。

依据：src/PlanetView.tsx / src/app.js · metrics / error

## 05 · 数据页

体成分查看与手动录入

### D-01 打开与收起录入 · 已实现 · 内联表单

点「录入」展开骨骼肌量(kg)、水分(%)、骨量(kg)、体脂率(%)四字段。
点「收起」隐藏表单；切换底栏仍保留表单开关与字段值。
边界：没有取消/回滚，输入框可访问名称仍为通用占位文案。

依据：src/App.tsx · manualEntryOpen

### D-02 编辑字段 · 已实现 · 立即更新

输入时直接更新 bodyMetrics，指标卡和生态比例立即随之改变。
输入值并非独立草稿，无需点击保存就已进入应用状态。
边界：无必填、数值、范围与单位校验；空值或非法文本可能产生 NaN。

依据：src/App.tsx · InputField onChange

### D-03 保存反馈 · 原型 · 状态提示

点保存：收起表单并持续显示「数据已保存，星球地貌正在重组。」。
未写入本地存储或服务端；刷新后恢复默认指标。
仅区域详情数值同步，尚无地形重组；建议反馈文案与真实结果一致。

依据：src/App.tsx · entrySaved / src/app.js

### D-04 评分与趋势 · 原型 · 静态数据

综合评分 87.3、超越 83%、构成 42/18/38/2、12 月趋势及本月 +18% 均固定。
动态指标名称旁的数值来自 bodyMetrics，构成百分比未同步计算。
「查看本月数据」暂无操作；趋势图没有筛选与点选详情。

依据：src/App.tsx · stats view

### D-05 录入规范建议 · 待完善 · 功能建议

建议：独立草稿 → 校验 → 保存成功后同步 → 可取消。
百分比应在 0–100；kg 应为有限正值，具体业务上限由产品确认。
保存失败保留输入并可重试；禁用重复保存，提供字段标签与错误提示。

依据：交接建议 · 对应 G-03

### 地形比例公式

四条为独立归一化指标，非地表面积占比。界面四舍五入显示，前三项没有下限保护；非法输入有风险。呼吸状况没有真实数据源。

| 地貌 | 来源 | 当前公式 | 默认显示 |
| --- | --- | --- | --- |
| 造山带 | 骨骼肌量 kg | min(100, muscle ÷ 60 × 100) | 71% |
| 深蓝寰海 | 体内水分 % | min(100, water) | 61% |
| 极地要塞 | 骨量 kg | min(100, bone ÷ 5 × 100) | 64% |
| 季风大陆 | 体脂 % / 固定稳定 | max(18, min(100, 100 − fat × 2)) | 63% |

### 建议加载状态机（未实现）

请求 → 轮廓加载 → renderer 首帧 ready → 显示球体；超时/失败 → 错误说明 + 重试。不得把 iframe onLoad 当作全部素材准备完毕。
