本轮是静态视觉交互设计，不是运行截图、可点击原型或功能完成声明。以当前 [交互基线](../../interaction-spec.md) 与 [产品说明](../../../PRODUCT_FEATURES.md) 为依据，覆盖首页、训练、生态、数据和我的五个标签。每张图将触发、目标状态和反馈并列展示。

## 采用的视觉

- 人物：第五/六轮的都市动画美漫 + 轻度写实，成人比例、自然面部结构与少量轮廓线；保留黑人、白人、东亚三位训练搭档的形象探索。示例主搭档 Maya 只用于保持各流程画面一致，不代表已锁定默认角色。
- 界面：B3 的炭黑与石墨灰表面，鼠尾草绿行动色，低饱和青蓝数据色；陪伴语气克制、正向。
- 星球：首页保留小型只读预览，生态保留完整三维球体与区域详情。
- 身体分析：保留正常人物与半侧骨骼/肌肉透明示意的纵向分界。仅借用第八轮透视结构，不沿用其简化卡通人物，也不采用怪诞科幻喜剧脸。
- 面向欧美首发的页面文案用英文，评审注释用中文；英文文案为设计草案。

## 阅读标记与示例数据

实线表示现有主流程的视觉重绘，虚线与“建议”表示尚需功能实现的优化。这种区分描述流程依据，不代表新视觉已接入。

统一示例：用户 Alex；主搭档 Maya；LV.5；经验 320 / 800 XP；周训练 3/5；骨骼肌量 32.8 kg、水分 58.3%、骨量 3.1 kg、体脂 18.7%。不是运行默认数据、真实用户指标、评分或医学标准。四项不相加为 100%。训练结算沿用 +46 XP 的奖励预览，不能与任务奖励混同。
