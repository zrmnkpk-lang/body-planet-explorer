## 已确定的设计决策

| 范围 | 决策 |
| --- | --- |
| 主风格 | 暗黑、潮流、现代科技运动；用自然色和地貌缓和硬朗感 |
| 人物 | 原创虚拟成年人，都市美漫轮廓与轻度写实结构，小幅卡通化；自然表情和运动体态 |
| 多背景 | 保留黑人、白人、东亚三个角色参考；能力、陪伴定位与奖励一致 |
| 示意角色 | Maya、Jordan、Kai 为工作名；Maya 是流程图示例搭档，未定义用户默认或正式命名 |
| 身体分析 | 正常人物与半侧骨骼/肌肉透视；面部仍采用选定成熟画法 |
| 世界 | 完整连续球体、地形比例克制、海陆与水系连贯，近看有真实结构、远看有游戏可读性 |
| 核心页面 | Home / Train / Planet / Body / Me 五项底栏，保持现有范围 |
| 语言 | 产品页面英文，项目评审与开发说明中文；人名与数值均为演示 |
| 游戏化 | 任务、XP、等级、五阶段和生态反馈；先完善训练与数据闭环 |

退出当前方向的探索：黏土玩具、大眼萌化、过度霓虹、怪诞科幻喜剧脸、四种美漫候选的未选方向。仓库仅保留最终可用参考，探索过程通过版本历史与原生成会话追溯。

## 项目分工与接入顺序

ChatGPT 负责美术生成、资产规格、页面规划和视觉验收；GLM 负责状态、计时、保存、触屏选区、数据同步及渲染接入。本轮只提交这些设计和需求，未启动功能实现。

建议先做一个可验收小切片：首页 → 训练选择 → 完成 → Planet；角色、按钮和同一颗星球贯穿。随后完善 Body 草稿/保存和 Me 数据一致性，再扩展角色选择与地貌演化。阶段解锁、地形变化幅度、正式奖励数值尚未定稿，不能从概念图推算。
