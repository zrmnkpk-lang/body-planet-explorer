## 已确定的设计决策

| 范围 | 决策 |
| --- | --- |
| 主风格 | 暗黑、潮流、现代科技运动；用自然色和地貌缓和硬朗感 |
| 人物 | 原创虚拟成年人，都市美漫轮廓与轻度写实结构，小幅卡通化；自然表情和运动体态 |
| 多背景 | 保留黑人、白人、东亚三个角色参考；能力、陪伴定位与奖励一致 |
| 示意角色 | Maya、Jordan、Kai 为工作名；Maya 是流程图示例搭档，未定义用户默认或正式命名 |
| 身体分析 | 正常人物与半侧骨骼/肌肉透视；面部仍采用选定成熟画法 |
| 世界 | 完整连续球体、地形比例克制、海陆与水系连贯，近看有真实结构、远看有游戏可读性 |
| 核心页面 | Home / Train / Body Planet / AI Coach 四项底栏；账户功能通过 Home 左上按钮展开左侧抽屉 |
| 首页顶部 | 小圆形账户头像；去掉右侧三条杠；右上提醒缩小；保留可用触控区域 |
| 账户抽屉 | 只保留账户信息、会员开通入口、设置；Weekly goal 等训练数据不在抽屉首页重复展示 |
| 会员入口 | Membership 卡与 Upgrade membership 按钮进入方案详情；价格、周期、权益与支付尚待定义和实现 |
| 语言 | 产品页面英文，项目评审与开发说明中文；人名与数值均为演示 |
| 游戏化 | 任务、XP、等级、五阶段和生态反馈；先完善训练与数据闭环 |

退出当前方向的探索：黏土玩具、大眼萌化、过度霓虹、怪诞科幻喜剧脸、四种美漫候选的未选方向。仓库仅保留最终可用参考，探索过程通过版本历史与原生成会话追溯。

## 项目实施与接入顺序

当前项目由 Codex（ChatGPT）统一负责规划、交互/UI、美术资产、功能开发、验证和文档维护；按需求直接完成工作，不再采用分模型开发或转交其他助手的流程。待实现需求与已完成能力仍需明确区分。已接入星球美术优化和图鉴导航；训练与身体数据闭环仍为待实现需求。

建议先做一个可验收小切片：首页 → 训练选择 → 完成 → Body Planet；随后完善融合页身体数据的草稿/保存、账户抽屉和 AI 主标签，再扩展角色选择与地貌演化。阶段解锁、地形变化幅度、正式奖励数值尚未定稿，不能从概念图推算。
