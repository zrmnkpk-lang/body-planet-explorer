## 1. 产品范围与数据

## 3. Train：自由训练 / 按计划训练

最新目标见 [训练页 v2 交接与图册](../visual-interactions/2026-10-07/TRAIN.md)，替代上一版训练入口；现状代码仍以 interaction-spec 为准。

| 状态 | 内容与动作 | 目标规则 |
| --- | --- | --- |
| 无当天计划 | No plan for today / Start free workout | 显式点击直接开始自由会话，再添加动作；进入页面不计时 |
| 有当天计划 | Today's workout，名称/总时长/动作数，View workout | 点击进入计划内容预览；仍可选择自由训练 |
| 计划内容 | 热身/主训练/放松分组动作，组次或时长，Start planned workout | 显式开始才计时，绑定当天计划与版本快照 |
| 自由训练 | Free workout / Add exercise / Pause | 可从空动作开始，在会话中选择并确认动作；空会话不发完成奖励 |
| 添加动作 | 搜索、筛选、选择、Add selected | 独立选择草稿；取消不改会话，无选择禁用确认；确认一次性加入 |
| 按计划执行 | 当前动作/组/目标、下一动作、Complete set | 按计划顺序，完成/跳过记录明确，动作完成由用户记录 |
| 暂停/恢复 | Pause / Resume workout | 同一时刻一个会话，切页/返回沿用状态与计时 |
| 结束/结算 | Finish workout，继续/结束确认，实际时长与记录 | 完整/部分/空会话区分；唯一结算，失败保留记录重试 |

从首页展开计划后点击训练入口，直接进入该计划内容而非启动会话；首页图中的 Start training 文案应调整为 View workout。计划内容为 20 分钟、5 个动作的演示，不替代现有训练模板数值，不冒充个性化训练指导。

正式实施需定义动作库、组次/时长目标、休息与阶段切换、完成判定和奖励。原三种模式（Mountain Strength 45min / 310kcal、Monsoon Cardio 30min / 420kcal、Morning Recovery 20min / 160kcal）保留为既有模板参考，不强制插入新流程；热量只可标估算。无数据源时不画心率、不宣称自动识别动作。

记录、任务完成、历史、XP 和周进度关联同一 sessionId；自由训练不默认完成指定计划。运行中使用计划快照，不受首页后续草稿编辑追溯影响。G-TRAIN-v2 的完整验收与待定业务规则见交接文档。

## 4. Body Planet：身体与生态同页联动

构图与流程见 [V5 融合页](../visual-interactions/2026-10-11/README.md)。单一内容流：完整球体 → 身体分析卡（小幅半边透视示意 + 四指标）→ Update body data。球体保持主要视觉焦点，身体图只在下方分析卡；球体视口没有头像或人物提示条。小屏自然滚动，不把身体/生态拆成两个主页面或必须切换的子标签。

| 状态 / 操作 | 页面反馈 | 目标规则 |
| --- | --- | --- |
| 球体加载 / 失败 | 占位、Loading your planet… / Retry | 以首帧 ready 判断，不仅 iframe onLoad；失败不阻断数据查看/编辑 |
| 就绪 / 探索 | 完整球体、侧边旋转/缩放/复位、下方身体卡 | 同一地形源与 renderer；触屏短按和拖动区分 |
| 点身体指标 | 指标选中并关联地貌或气候层，展开详情 | Muscle→山脉、Water→水域、Bone→极地、Body fat→气候；数值只有一个来源 |
| 点球体区域 | 同步选中对应指标并显示相同详情 | 背面标签隐藏；停止自转；不另建重复数据 |
| 聚焦 / 返回 | Focus region / Back to overview | 同源相机聚焦，返回恢复全貌；气候是图层关系，不虚构固定脂肪大陆 |
| 身体编辑 | 四字段、单位、独立草稿；Cancel / Save changes | 草稿不改变已保存数据/球体/首页；确认保存才发布新值 |
| 校验 / 失败 | 就近错误、保留草稿、可重试 | 空值/非数字/NaN/Infinity 不保存；百分比 0–100，kg 正数，上限另定 |
| 无指标 | 四值 —，Add body data | 可以看艺术示意星球，不填伪造身体记录 |

保存成功同步首页身体摘要、融合页四指标与区域详情；没有几何演化实现时只写 Body data updated，不宣称重建地形。刷新恢复与记录时间/来源必须有实际存储支持。身体透视是艺术示意，不是扫描；不由人物比例或球体外观推断身体数值。旧 [生态规范](../visual-interactions/2026-10-07/PLANET.md) 的操作和 [星球美术](PLANET_ART.md) 的地貌关系继续适用，旧独立页面布局已替代。

## 5. Account：Home 左侧账户抽屉

账户内容放入 Home 左上角小头像打开的左侧抽屉。V6 简化为账户信息、会员开通入口、设置三个区域，保留 Account 标题与 X。抽屉约 84vw、桌面最大 360px，保留右侧遮罩；页面与底栏属于不可交互背景，关闭恢复首页位置和触发按钮焦点。

| 内容 | 操作 | 状态与迁移规则 |
| --- | --- | --- |
| Account information | 小头像、Alex、副标题、右箭头；整行进入资料页 | 只展示账户资料，使用已接入字段；无账户服务时标为本地资料 |
| Membership | 会员状态、Explore membership options、Upgrade membership 按钮 | 独立细黄绿边框卡；Free plan 为示例，实际状态由账户服务读取；按钮打开会员方案详情 |
| Settings | 齿轮、Settings、右箭头；进入设置页 | 紧凑行，集中实际可用的偏好与设置，不留空点击 |

Weekly goal、Training partner、Daily reminder、Explore Body Planet、等级与 XP 不放在抽屉首页。周进度与成长信息继续在 Home；搭档选择和提醒偏好如后续保留则放到设置子页，确认/取消和同步规则保持有效。

会员入口先到方案详情，后续由用户查看真实价格、周期、权益，选择方案并确认支付。按钮本身不直接扣款；本轮未设计完整收银页或接入支付。方案待定时不填虚构价格、折扣或权益，读取失败保留重试，不用示例会员状态覆盖真实状态。

X、遮罩、Escape 或系统返回关闭抽屉。进入资料、会员、设置子页后先返回抽屉；编辑取消丢弃草稿，不误保存。已有角色图为概念，不裁整张图当正式头像套件。抽屉自身没有第二套底栏。旧 Me 深链应到 Home + Account，不能因第四项变化误打开 AI。

## 6. AI Coach：第四主页面

AI Coach 常驻第四项底栏。Home / Train / Body Planet 的 Ask AI Coach... 横框切到同一对话并聚焦输入；直接点 AI 标签恢复已有消息/草稿，不自动发送问题。AI 页使用一个真实输入框，键盘关闭时四项导航可见；键盘打开时导航临时收起，输入随可视视口上移。

由快捷横框进入时显示 From Home / From Train / From Body Planet，可查看已关联主题。额外身体记录按需加入，缺失时补问信息。快捷问题先填入，确认发送才请求回复。主导航切换不清空对话/输入，也不结束训练；用户可以停止生成。

Agent 可解释动作、整理计划、提出调整草案。Suggested draft → Review plan → Save to today / Cancel；保存前检查日期、版本、动作和目标，取消保留旧计划。回复不直接改写正在执行的会话、记录完成或发放奖励。状态包括未接入 Preview、无上下文、生成/停止、失败重试、草案/版本冲突。细节见 [Agent 能力](../visual-interactions/2026-10-07/HOME-AI.md)，其中入口与导航以 V5 为准。

## 7. 跨页状态与信息规则

1. Home 的 View plan 只展开当日计划，训练项 View workout 打开计划内容；Start planned workout 才开始按计划训练，Start free workout 直接开始自由训练并允许随后添加动作。进行中切页后保留同一会话，不能切回时重新奖励或重置。
2. 完成结算有唯一记录，更新 XP、周进度和任务；撤销手动任务与训练记录的关系由 G-02 明确，不静默删除真实训练。
3. Body Planet 编辑草稿与展示数据隔离；成功保存才发布新值，取消/失败保留旧值和相机。
4. 出现人物的页面沿用同一搭档，Body Planet 球体视口不加人物头像，下方分析卡保留身体示意；同一用户身份、同一 XP/等级跨页一致；风格与装备不因小头像而换成萌化版本。
5. 刷新后的恢复取决于已实现的存储能力。未接入存储时仍如实描述会话状态，不能只用成功 toast 假装持久化。
6. 四项导航保持标签、安全区与明确高亮；前三页是 AI 快捷横框，AI 主页是真实输入框。账户抽屉/模态打开时背景横框和导航不可交互；关闭恢复焦点。沉浸训练/编辑页沿用专用控件，退出恢复原主页面。
