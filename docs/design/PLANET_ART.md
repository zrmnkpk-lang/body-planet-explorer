## 1. 星球身份与构图

星球是身体生态的可探索世界。全貌保持完整球形、连续海陆和清晰主山脉，近看有岩层、水系、树林与湿地结构；地形具有轻度写实的自然逻辑，同时用概括形体保持手机上的可读性。整体与成熟运动搭档同属一套游戏美术语言。

参考图：[全貌](planet-concepts/01-planet-overview-v1.png)、[多地貌](planet-concepts/02-planet-biome-atlas-v1.png)、[五阶段](planet-concepts/03-planet-five-eras-v1.png)、[探索尺度](planet-concepts/04-planet-exploration-scale-v1.png)、[身体映射](planet-concepts/05-planet-body-data-mapping-v1.png)。它们定义风格和关系，不是精确球面地图或可直接导入的贴图；生成图的视角间地理细节可能有偏差，生产时必须以同一个种子/地形源生成各视角。

当前已接入：`planet.html` 的八类地形/七类天气水流图鉴、对应位置导航、完整远景山脊与主水系、日光与蓝绿水体色板、混合树林、柔边薄云，以及 v3 层岩/冰台模型。第二轮具体参数与限制见第 12 节，前文 v2 数值为第一轮历史记录。APP 共享这些模型和美术参数；图鉴面板仅显示在独立演示页。人物与五页 UI 全面改版仍未接入。

| 视觉锚点 | 作用与构图规则 |
| --- | --- |
| 西部主山脉 | 主要轮廓识别点，连续脊线、多级坡面，衔接丘陵和平原 |
| 东南河谷 | 河流由高地汇入湖泊/海洋，呈现主流、支流和湿地 |
| 北极冰盖 | 冰雪集中于高纬和高海拔，白色用于清晰轮廓而非覆盖所有峰顶 |
| 海洋与大陆架 | 深海深蓝、浅海低饱和青蓝，海岸逐渐过渡，避免整球亮青 |
| 远侧干旱大陆 | 赭色与风化岩层增加转到背面后的差异，不另换一种画风 |
| 岛链与季风海岸 | 小岛和较绿海岸作为第二层探索内容，不遮挡主地形 |

全貌允许少量薄云和柔和大气边缘，云覆盖不得阻断关键区域识别。日光为默认清晰状态，暮色为可选情绪参考，正式版本不能因为暗黑界面让球体本身过暗。球体不增加脸、眼睛、玩具底座、巨大漂浮建筑或装饰环。

首页小球与 Planet 大球使用同一地形、颜色和角色世界观。首页保持只读慢速预览，Planet 承担交互；阶段卡切换本身不代表几何演化已经实现。

## 2. 地貌图谱

| 地貌 | 形体与材质 | 相邻关系 / 细节 |
| --- | --- | --- |
| 山脉与岩脊 | 石板灰、褐灰分层岩石，主峰/次峰/山麓三级尺度 | 与丘陵、河源、雪线相接；峰高克制，避免刺猬球 |
| 河流与湿地 | 青蓝水、低地草甸、芦苇与泥岸 | 河网连续且顺地势，湿地在低洼和入海口，避免孤立蓝线 |
| 森林与草原 | 深浅两级自然绿，混合树高与疏密 | 沿湿润地带集群，山脊/荒漠/冰面留空；禁止均匀撒树 |
| 海岸与河口 | 沙、岩、浅滩和深水有层次 | 港湾/岬角/岛屿形成不同轮廓，水岸接缝不得露出裂缝 |
| 干旱高原 | 低饱和赭黄、红褐岩台、风化层 | 向草原渐变，少量耐旱植被；保留自然美感 |
| 冰川与峡湾 | 冷白和灰蓝冰、暗色岩石、层状裂隙 | 极地与高山雪源相连，峡湾注入海洋，避免巨型水晶 |
| 火山岛链 | 深灰玄武岩、旧火山口和磨蚀海岸 | 可作为早期陆地，活动效果需另立事件规则；默认无夸张熔岩 |
| 开放海洋 | 深蓝大面、浅微纹理、轻微高光 | 全貌保留足够静区，海面不密布白色高频浪花 |

近距离纹理为形体补充，不用噪点替代岩层与河网。树、草、石、冰块密度按画面与性能控制；目标是自然层次，而不是堆满所有可见表面。

## 3. 五阶段的同源演化

五阶段继承现有名称，英文为页面改版草案。所有阶段采用同一相机、光向、球体尺度和海陆锚点做对照；阶段变化保留识别关系，避免五颗互不相干的球。

| 阶段 | 英文 | 主视觉变化 | 保留 / 不提前出现 |
| --- | --- | --- | --- |
| L1 沧海纪 | Ocean | 海洋主导、洋流与低矮海底/露出岩脊 | 保留后续大陆的大致锚点；没有成熟森林和巨大山系 |
| L2 露陆纪 | Emergence | 岛链、裸岩海岸与初生陆地 | 与 L1 同源，岩面为主，植被稀少 |
| L3 山脉纪 | Mountains | 主山脉成形、雪线、初生高山湖与少量草地 | 保留海岸和岛链，不一次性加入完整河谷森林 |
| L4 江河纪 | Riverlands | 连续水系、河谷、湿地、较年轻的林地 | 山脉/极地仍可辨，水系连通而非随机绘制 |
| L5 丰壤纪 | Flourishing | 成熟森林、草原、荒漠、海岸与完整生态差异 | 保留前四阶段的关键轮廓，丰富但不全绿 |

本图只确定阶段的美术关系。阶段解锁 XP、训练次数、是否回退、过渡时长与身体指标关系需作为功能规则单独决定。当前阶段卡可自由浏览，完整实时球体不随五阶段浏览切换；在 GLM 接入前必须如实显示此边界。

首页阶段背景独立制作：只含地貌，不烘焙文字/按钮/球体，正文区域保留低对比空间，右侧小球轮廓清晰。当前五张 WebP 保持运行，替换规范见 [卡片背景](../card-background-assets.md)。

## 4. 探索尺度与地标

视觉上规划全貌 → 大陆 → 区域三个观察层；技术上继续使用现有连续球面和语义细节系统，避免新增第二套地形实现。概念中的近景是轨道相机观察，不定义地面行走或第一人称探索。

| 尺度 | 应看到 | 不应看到 |
| --- | --- | --- |
| 全貌 | 完整球形、海陆比例、主山脉与冰盖，少量可辨区域 | 密集地点标签、独立草叶、占满球体的轮廓高亮 |
| 大陆 | 主要河网、森林集群、山脊结构与较少地点 | 背面标签透出、地形破裂、突然切到另一颗球 |
| 区域 | 河岸、岩层、湖泊、自然植被、当地地标 | 可交互外观的假道路/建筑、首人称 HUD、地貌被控件遮住 |

区域聚焦先改变相机，不改变世界种子。选中轮廓用细线和一个定位点；详情包含名字、对应指标与 Focus/Back，主信息在独立卡片中排版。关闭详情回到全貌，重置恢复默认视角，自转可手动关闭。

当前地标 `basalt.glb` 与 `glacier.glb` 已通过原生成脚本更新为 v3：玄武岩增加相连岩台与碎石，冰台降低高度并加入连续冰座；分别 900 / 496 个三角面，各一个网格，体积 98,548 / 54,912 bytes。区域名和位置继续由 `src/landmarks.js` 唯一维护；图鉴通过 landmark ID 引用坐标，不再复制一份坐标表。

当前五级技术细节 skyline / continent / climate / ecology / surface，以及网格和实例数量，以 [desktop-terrain.md](../desktop-terrain.md) 为准。手机 GPU 预算需在实际设备测量；本概念册不新增网格面数或性能承诺。

## 5. 身体指标的艺术语义

| 输入 | 单位 | 地貌语义 | 视觉可用表达 |
| --- | --- | --- | --- |
| 骨骼肌量 Muscle | kg | 造山带 Mountain Belt | 山脊结构与起伏感，维持海陆连贯 |
| 体内水分 Water | % | 深蓝寰海 Deep Ocean | 海洋深浅与水系表现，不将数值直接当海洋面积 |
| 骨量 Bone | kg | 极地冰盖 Polar Ice | 冰层结构与轮廓，保持极地位置 |
| 体脂率 Body fat | % | 季风/气候 Monsoon Lands | 季节和植被分布语义，避免污染、腐败或身体惩罚隐喻 |

四项各自有独立单位和来源，不能相加当作 100% 的球面划分，也不应把球体切成四块地形。现有归一化公式仅作用于显示条，不是科学模型或目标地貌面积；精确公式见现状交互基线。

本轮没有定义“数值越高山越高”或“体脂越低世界越好”的健康判断。G-05 接入前需定义适用范围、平滑规则、缺失值、异常值、种子稳定性和回退方案。优先让已保存数据更新数值卡，再以小幅、渐进且可解释的视觉反馈扩展地貌。

训练生态事件与指标编辑分开：力量/有氧/恢复可分别对应山脊、季风、晨雾的短反馈；训练奖励、事件触发和地形变化不能从一张结算图直接推导。当前只展示事件预告，无真实地质重组。

## 7. 视觉验收与实现验收

视觉检查：完整球体各角度有差异；山峰高度适中；海岸/河网无悬断；植被疏密自然；冰雪位置合理；五阶段可辨且同源；区域聚焦地理连续；地标不浮空；地图标签不遮住主要形体；背景与数据文字有足够对比。

工程检查：`node scripts/validate-planet.mjs` 和 `npm run build`；浏览器检查演示页图鉴、主题定位、近景地标、气候层和 APP 嵌入。新增数据演化时需额外检查非法输入、缺失数据、重复保存和性能退化。当前模型、美术和图鉴的验证记录见 [地形实现文档](../desktop-terrain.md)；后续天气/成长机制未实现。

## 9. 地理、气候、缩放和身体语义的关系

地理骨架来自 `continents.js` 的 7 组大陆/极地轮廓，叠加岛链、三维噪声与高度场。西境造山带与季风大陆是同一主陆块的不同语义区；另外包含赤砂、背面湿润大陆、岬湾、南风、东岚与北极图形。地貌围绕连续经纬度分布，不按身体指标切成四个扇区。

| 系统 | 当前驱动 | 与其他系统的关系 |
| --- | --- | --- |
| 海陆与山地 | 固定轮廓、种子、山带/高原高度场 | 河床、法线、植被锚点和拾取共用相同表面 |
| 森林、草原、荒漠 | 海拔、坡度、湿度与干旱遮罩 | 林缘与地表着色一致；雨云避开明显干旱和极地区域 |
| 河湖与湿地 | 51 条河道（含 12 条三角洲分流）、7 湖、3 湿地 | 河床/水面/岸缘共享轮廓；水位沿下游下降，四条峡湾接外海 |
| 气候 | 固定地理锚点、种子和时间 | 独立于身体输入；仅海洋气旋可与附近活跃风暴联动 |
| 观察层级 | 相机距球心的距离和连续权重 | 五层为观察尺度，不是 L1–L5 成长阶段 |
| 身体数据 | `muscle / water / bone / fat` | 只更新说明卡数值，尚未生成新大陆、改变雨量或生长森林 |

| 观察按钮 | 距离 | 主要展示 |
| --- | ---: | --- |
| 天际 | 4.2 | 整体海陆、主脊与薄云；本轮远景保留 58% 高度，不再过度压平 |
| 板块 | 3.45 | 海岸、大陆/群岛名称与地貌色带 |
| 气候 | 2.78 | 风带、雨云、气旋和主水系，天气权重接近完整 |
| 生态 | 2.12 | 主/支流水系、森林实例、山麓与峡湾 |
| 地表 | 1.53 | 低矮植被、岩石、冰体、芦苇、v2 地标和过滤后的程序化细纹 |

层级边界有滞回，细节平滑渐显；地形在植被出现前恢复全高度。近景仍保留少量云与天气，不定义地表步行。减弱动态效果当前只关闭闪电并冻结水面流纹，风云仍运动；完整静态气候模式是待完善项。
