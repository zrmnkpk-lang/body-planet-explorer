# Portal Fitness 交互设计文档 v1
> 版本 v1.0 ｜ 2026-09-08 ｜ 基于产品方案 v1 的功能框架整理
> 范围：MVP 全部模块 + V1 关键模块的页面结构、用户流程、交互细节与反馈规范

## 1. 全局信息架构

### 1.1 底部导航（4 Tab）

| Tab | 名称 | 核心内容 | 选中态 |
|-----|------|----------|--------|
| 1 | 星球 | 星球总览卡（入口）、守护者叙事、今日训练入口、每日任务、连击 | 亮蓝 #4582E6 类高亮 + 图标点亮 |
| 2 | 训练 | 快速开始、模式选择、训练中、训练结算 | 同上 |
| 3 | 数据 | 星球生态全览、体成分四件套、手动录入、趋势（V1）、报告入口 | 同上 |
| 4 | 我的 | 身份等级、徽章（V1）、设置、后续能力入口 | 同上 |

> 结构说明：Tab1 是「今天的星球」情绪面，Tab3 是「长期的数据」理性面。星球在两处都出现但职责不同——首页是快照卡（3 秒扫一眼），数据页是全览（可交互、可下钻）。

### 1.2 页面层级清单（MVP）

```
L1  星球(首页) / 训练 / 数据 / 我的
L2  ├ 星球页全览（点首页星球卡进入）
    ├ 训练模式选择页 → 训练进行页 → 训练结算页
    ├ 体成分手动录入页
    ├ 每日任务页（首页任务卡展开）
    └ 设置 / 关于 / 减少动效跟随系统
L3  └ 生态事件详情浮层 / 守护者对话半屏（V1）/ 徽章详情（V1）
```

## 2. 模块交互设计

### 2.1 首页（星球 Tab）

**页面结构（自上而下）**

| 区块 | 内容 | 交互 |
|------|------|------|
| ① 状态栏区 | 连击火焰 × N 天 ｜ 观察员等级与 XP 条 | 点连击 → 连击规则浮层；点 XP 条 → 等级详情 |
| ② 星球总览卡（视觉主体，约 45% 屏高） | 当前状态插画 + 今日生态事件标签 | 单击 → 转场进入星球页全览（共享元素转场，星球放大）；下拉刷新 → 事件流更新 |
| ③ 守护者叙事条 | 头像 + 1 条今日气泡文案（轮播 2-3 条，5s/条） | 单击 → 叙事详情；长按 → 换一条（梗交互：「换一个说法」） |
| ④ 今日训练入口 | 大按钮「开始今天的训练」+ 推荐模式一句话 | 单击 → 直达训练模式选择页 |
| ⑤ 每日任务卡 | 2-3 条任务，完成态荧光绿对勾 | 单条 → 跳转对应功能；全完成 → 卡片变身奖励态（黄色） |

**关键交互细节**
- 星球卡在页面加载时执行**入场扫描动效**（扫描线 600ms），之后保持黑洞慢速旋转 + 粒子环绕待机动效（低成本循环）。
- 每日任务有新完成时，任务卡右上角弹出黄色贴纸角标 + 轻微弹跳（200ms），**不自动领奖**——让用户自己点，制造领取快感。
- 空态（新用户）：星球卡显示 L0 荒芜星 + 引导文案「你的星球刚诞生，它需要第一场训练」。

### 2.2 训练模块（MVP 闭环核心）

**流程：模式选择 → 训练进行 → 训练结算 → 生态事件**

| 页面 | 结构与交互 |
|------|-----------|
| 模式选择页 | 3 张大卡：力量（造山）/ 有氧（季风）/ 拉伸恢复（晨雾）。每卡 = 模式图标 + 预计时长 + 对应星球事件预告（「这次训练会带来一场造山运动」）。单卡点击 → 训练进行页。底部次按钮「换一批（V1）」 |
| 训练进行页 | 顶部：模式名 + 计时；中部：当前动作/阶段 HUD 框（科幻边角线风格）；底部：暂停 / 结束。训练数据实时显示（Bangers 数字字体）。**关键反馈**：每完成一组/一个阶段 → 屏幕边缘荧光绿粒子轻扫（300ms）+「正在变强」微文案 |
| 训练结算页 | 三段式：① 训练数据总结（时长/模式/XP 数值滚动动画 1.2s）② **生态事件预告卡**（事件插画缩略 +「一场造山运动正在你的星球发生」）③ 主按钮「去星球看看」+ 次按钮「回到首页」 |
| 中断/异常 | 训练中退出 → 确认弹窗（守护者口吻：「星球刚感觉到板块在动，现在停下吗？」）；中断已超 5 分钟 → 按已完成部分结算，不给全额 XP |

**设计要点**：结算页的「去星球看看」按钮是整个养成闭环的传动轴——点击后转场到星球页并**自动播放今日事件动效**（800-1200ms），这是生死线指标（星球页访问率）的第一跳。

### 2.3 数据页（星球页）

**页面结构**

| 区块 | 内容 | 交互 |
|------|------|------|
| ① 星球全览 | 全宽状态插画（可双指缩放 1.0-1.5x）、事件图层循环播放 | 单击事件标签 → 事件详情浮层（发生时间、触发行为、相关数据） |
| ② 星核能量值（综合评分） | 大数字 + 环形进度 | 单击 → 评分构成明细（各维度贡献） |
| ③ 体成分四件套 | 肌肉量/水分/骨骼量/体脂 四个 HUD 小卡，各映射地理要素缩略图 | 单卡 → 该指标趋势（V1：曲线图；MVP：最近 3 次记录列表）；右上「+」→ 录入页 |
| ④ 体成分手动录入 | 数字键盘 + 四项输入 + 记录时间 | 保存 → 「地质活动」确认动效（星球对应区域微变化 800ms）+ 守护者播报 |
| ⑤ 报告入口（V1，占位） | 「纪元变迁」灰置入口 + 预告文案 | MVP 灰置，点击 → 「V1 即将到来」贴纸提示 |

**录入细节**：四项中允许只填部分；数值异常（如体脂 3%）→ 黄色警示「这个数字有点离谱，确定吗？」（不阻断，幽默不教训）。

### 2.4 游戏化系统交互

| 系统 | 触发点 | 反馈设计 |
|------|--------|----------|
| XP 获取 | 训练结算、任务完成 | 数字滚动（Bangers 字体，1.2s，缓出）；XP 条充满 → 升级全屏横幅（1.5s，可点击跳过）+ 解锁内容预览 |
| 连击 | 首页状态区、训练结算 | 连击数火焰动效；7 天节点 →「绿洲爆发」全屏粒子（1.2s）；断签 → 不弹惩罚弹窗，只在下次打开时守护者温和提及 + 给出「复苏任务」 |
| 每日任务 | 首页任务卡 | 完成打勾（荧光绿 200ms）；领取 → 黄色奖励爆开 + XP/事件预告 |
| 成就徽章（V1） | 我的页徽章墙 | 漫画贴纸风格、随机倾斜角度；解锁时贴纸「拍」上屏幕（scale 0.6→1 + 微旋转，300ms） |
| 等级 | 全局 | 观察员等级≠星球生态等级，两套体系视觉分离：等级=数字徽章，生态=插画状态 |

### 2.5 个人中心（我的）

| 区块 | 内容 | 版本 |
|------|------|------|
| 身份卡 | 头像、昵称、观察员等级、星球名字（用户可给星球命名，MVP 即支持——低成本高归属感） | 【M】 |
| 本周概要 | 本周训练次数/时长/连击 | 【M】 |
| 徽章墙入口 | → 徽章列表 | 【V1】 |
| 设置 | 推送开关、减少动效跟随系统说明、账号、数据删除（合规必须） | 【M】最小集 |
| 后续能力 | 设备接入、数据导出等灰置占位 | 【M】灰置 |

## 3. 三条关键用户旅程

### 3.1 新手首启（目标：首次训练完成率）

```
欢迎页（星球出生倒放动画 2s，可跳过）
→ 守护者初见对话（3 步气泡，最后一步给星球起名）
→ 基础数据（身高体重选填，明确告知「跳过也没关系」）
→ 首页（L0 荒芜星空态）→ 强引导：唯一大按钮「带它开始第一场训练」
→ 模式选择（默认选中拉伸，最易完成）→ 训练 → 结算
→ 「去星球看看」→ 播放第一场生态事件 → 升级提示 L0→L1 进度可见
```
> 设计原则：首启流程 ≤ 3 分钟进入第一次训练；所有非必需输入后置。

### 3.2 日常训练反馈闭环（核心循环）

```
首页「开始今天的训练」→ 模式选择 → 训练中（边缘粒子微反馈）
→ 结算页：XP 滚动 → 生态事件预告卡 → 点「去星球看看」
→ 星球页自动播放事件动效 + 守护者播报 → 引导「明天同一时间，星球等你」（预约提示，可关）
```

### 3.3 报告上传仪式（V1，纪元变迁）

```
数据页「纪元变迁」→ 上传报告 → 扫描线全屏动效（3s）
→ 解析中（守护者吐槽文案轮换：「正在解读星球的古老岩层…」）
→ 结果页：合规体成分四件套以星球地理重组动画呈现（5s cutscene，可跳过）
→ 纪元命名（用户输入纪元名，存入星球编年史）→ 星球状态升至 L4 或触发地质重绘
```

## 4. 交互反馈规范（全局）

### 4.1 状态色规范（不使用 emoji，跨平台稳定）

| 语义 | 颜色 | 应用 |
|------|------|------|
| 激活/导航/主操作 | 亮蓝 | Tab 选中、主按钮、链接 |
| 已完成/正向 | 荧光绿 + 对勾图标 | 任务完成、目标达成、训练段完成 |
| 警示/任务/奖励 | 黄色 | 异常数值提示、奖励角标、任务贴纸 |
| 空态/禁用/灰置 | 灰黑 | 未开放功能占位 |
| 危险操作 | 珊瑚红 | 数据删除、退出训练二次确认 |

### 4.2 动效分级与降级

| 级别 | 时长 | 用途 | 减少动效降级 |
|------|------|------|--------------|
| 微交互 | 100-300ms | 按钮按压、打勾、角标弹跳 | 直接显示终态 |
| 状态反馈 | 600-1200ms | XP 滚动、事件播放、录入确认 | 静帧 + 文字说明 |
| 仪式动效 | 3-5s 可跳过 | 新手出生、纪元变迁、徽章解锁 | 1s 快速版或跳过按钮常显 |

- 全部动效尊重系统「减少动态效果」设置：开启时待机粒子/黑洞旋转静止为静帧海报，功能不受影响。
- 待机动效（黑洞旋转、粒子环绕）仅在星球卡与星球页渲染，列表页一律静态——控电控帧率。

### 4.3 文案声音规范

- 全 App 文案统一守护者视角的星球叙事，短句、有梗、不羞辱、不焦虑。
- 训练提醒推送示例：「你的星球今天没有等来那场季风。（它没生气，就是有点想你）」
- 断签回归示例：「欢迎回来。生态还在，复苏任务已经挂好了——从一场 10 分钟的晨雾开始。」

## 6. 开放问题（下一轮设计输入）

1. 星球卡与星球页的「共享元素转场」在跨端框架中的实现成本，需技术预研。
2. 守护者叙事轮播的节奏（5s/条）是否过快，建议可用性测试验证。
3. 拉伸恢复模式的事件表现（晨雾）戏剧性偏弱，可能拉低「训练→事件」期待感，备选：改为「星空澄澈」。
4. 报告上传 cutscene 的 5s 时长与跳过策略，需真机验证节奏感。
