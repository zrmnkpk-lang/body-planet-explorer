# Portal Fitness 产品方案
> 版本 v1.1 ｜ 2026-09-15 ｜ 补充基础训练工具与周期进化机制
> 定位基线：宇宙漫画风格 · AI 生活健康陪伴 · 游戏化健身 · 身体成分养成

---

## 1. 产品概述

### 1.1 一句话定位

**你的身体是一颗星球。**

其他健身 App 帮你记录训练，Portal Fitness 让你亲眼看见自己的身体在变强——用户每一次训练都会为专属星球积累能量；当时间和 Credit 达到条件，星球将在周期性演化中产生永久地貌变化。

### 1.2 产品气质

| 维度 | 定义 |
|------|------|
| 核心气质 | 宇宙科幻 × 美式漫画 × 游戏化健身；荒诞、有能量、轻松幽默 |
| 情绪基调 | 不是「自律给我自由」的苦修感，而是「我在养一颗星球」的养成快感 |
| 视觉语言 | 深色宇宙背景 + 半透明灰黑模块；亮蓝/亮紫/荧光绿/黄高亮；黑洞、轨道粒子、扫描线、HUD 数据框；不规则贴纸、倾斜徽章 |
| 字体 | ZCOOL KuaiLe（中文标题/徽章）、Bangers（英文标题/数值）、Comic Neue（正文） |
| 动效 | 黑洞慢速旋转、多层轨道粒子、扫描/进度动效强调「正在变强」；支持系统「减少动态效果」 |

### 1.3 目标用户

**核心**：18-30 岁年轻用户，游戏化敏感人群，被 Keep 类工具型健身 App「劝退过」至少一次。

| 画像 | 特征 | Portal Fitness 的钩子 |
|------|------|----------------------|
| 健身萌新「三分钟阿伟」 | 想练但坚持不过两周，需要即时正反馈 | 星球的即时生态变化给每次训练可见意义 |
| 游戏型年轻人 | 被健身环大冒险教育过，吃收集/养成/成就一套 | 纪元变迁史诗 + 守护者 NPC 陪伴 + 徽章体系 |
| 轻亚健康白领 | 体检查出体脂偏高，想「科学地」动起来 | 体成分→星球地图的直观可视化 + 周度体脂秤反馈 |

## 2. 核心概念：身体星球

### 2.1 体成分 → 星球地理映射

| 生态要素 | 锚定数据 | 数据频率 | 变化表现 |
|----------|----------|----------|---------|
| 大陆板块与植被 | 骨骼肌量 | 周/月 | 训练积累→大陆隆起、绿洲扩张 |
| 海洋与河流 | 身体水分 | 周/月 | 饮水+有氧→河流动脉加速 |
| 山脉骨架 | 骨量 | 月/年 | 长期力量训练→山脉耸立 |
| 大气层 | 体脂率 | 周/月 | 体脂下降→云层散开、星空变清晰 |
| 星核能量 | 基础代谢/活动量 | 日 | 每日打卡→星核脉动亮度 |

### 2.2 生态状态机（MVP）

| 等级 | 状态名 | 进入条件 |
|------|--------|----------|
| L0 | 荒芜星 | 新手注册初始态 |
| L1 | 沧海纪 | 累计训练 3 次 或 连续打卡 3 天 |
| L2 | 露陆纪 | 连续 7 天打卡 或 周训练 ≥3 次 × 连续 2 周 |
| L3 | 山脉纪 | 连续 14 天 或 体脂秤月度改善 |
| L4 | 江河纪 | 纪元事件触发 |
| L5 | 丰壤纪 | 史诗成就 |

## 3. 基础训练工具

### 3.1 动作库

动作库覆盖力量、跑步、有氧器械、游泳、户外、拉伸恢复、瑜伽身心和球类综合运动。用户可以按名称、别名、肌群、分类和器械搜索，并收藏常用动作。

### 3.2 训练记录

| 运动类型 | 核心记录字段 |
| --- | --- |
| 力量训练 | 动作、组数、重量、次数、RPE、完成状态 |
| 跑步/骑行/步行/徒步 | 日期、开始时间、距离、时长、平均配速 |
| 游泳 | 距离、趟数、泳姿、时长 |
| 瑜伽/拉伸/球类 | 时长、动作或课程备注 |

训练支持自由记录、运动项目快速开始、从训练方案开始三种入口。完成后保存历史记录并结算 Credit；未完成训练保留为本地草稿。

### 3.3 训练方案

用户可以创建、编辑、删除训练方案，为方案设置每周频次和动作顺序，并从方案直接开始记录。AI 训练计划生成将在后续复用同一方案数据结构，并在安全规则校验后写入用户方案。

### 3.4 周期性星球进化

训练当下只产生星核发光、能量注入和地貌虚影等即时反馈；永久地貌变化需要同时满足时间门槛与 Credit 门槛。

| 进化次数 | 最短间隔 | 初始建议门槛 |
| --- | ---: | ---: |
| 首次 | 当天 | 60 Credit |
| 第二次 | 3 天 | 160 Credit |
| 第三次 | 5 天 | 240 Credit |
| 稳定期 | 7 天 | 320 Credit |

周期进化是一周级的小型永久变化；L1–L5 纪元跃迁是数周或数月级的大阶段变化，两者不共用同一进度条。

## 4. 守护者 NPC（AI 陪伴载体）
